Connect Phantom
one time · then it runs by itself every night

Phantom asks you to approve every transaction, so it can't trade while you sleep. Give the bot its own Phantom account instead: it trades from it, and you watch and withdraw from it in Phantom anytime.

فانتوم بيطلب موافقة على كل عملية، فمش هيقدر يتداول وانت نايم. اعمل للبوت حساب لوحده جوه فانتوم: البوت يتداول منه، وانت تشوفه وتسحب منه من فانتوم في أي وقت.

  1. Phantom → account menu → Add / Connect Wallet → Create New Account. Name it Grok Bot.
    في فانتوم: قائمة الحسابات ← Add / Connect Wallet ← Create New Account، وسمّيه Grok Bot.
  2. Settings → Manage Accounts → Grok Bot → Show Private Key → copy it.
    الإعدادات ← Manage Accounts ← Grok Bot ← Show Private Key ← انسخه.
  3. Paste it here. It's saved only in .env on this computer and never shown, logged or sent anywhere.
    الصقه هنا. بيتحفظ على الجهاز ده بس، ومش بيظهر أو يتبعت لأي حد.
  4. From your main Phantom account, send USDC or SOL to Grok Bot (Send → My accounts → Grok Bot). Keep at least 0.05 SOL in it for fees; extra SOL is converted to USDC automatically.
    من حسابك الأساسي في فانتوم ابعت USDC أو SOL لحساب Grok Bot. خلّي فيه 0.05 SOL على الأقل للرسوم، والباقي بيتحول USDC لوحده.
  1. Phantom → account menu → Add / Connect Wallet → Create New Account. Name it Grok Bot.
    في فانتوم: قائمة الحسابات ← Add / Connect Wallet ← Create New Account، وسمّيه Grok Bot.
  2. Settings → Manage Accounts → Grok Bot → Show Private Key → copy it.
    الإعدادات ← Manage Accounts ← Grok Bot ← Show Private Key ← انسخه.
  3. Railway → this service → Variables → New Variable: name SOLANA_PRIVATE_KEY, value = paste → Deploy. The bot restarts and goes LIVE by itself.
    في Railway: الخدمة ← Variables ← New Variable، الاسم SOLANA_PRIVATE_KEY والقيمة الصق المفتاح ← Deploy. البوت هيعمل ريستارت ويبقى LIVE لوحده.
  4. From your main Phantom account, send USDC or SOL to Grok Bot, keeping at least 0.05 SOL in it for fees.
    من حسابك الأساسي ابعت USDC أو SOL لحساب Grok Bot، وخلّي فيه 0.05 SOL على الأقل للرسوم.

Use only money you can afford to lose. Memecoins can go to zero in seconds. استخدم فلوس تقدر تستغنى عنها بس.
